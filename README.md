# customer_behavior_analysis
This project focuses on analyzing customer behavior to identify purchasing patterns, customer preferences, and key trends from customer data. The project involves data cleaning, exploratory data analysis, and querying data to understand factors such as customer demographics, purchase frequency, spending patterns, and product preferences.

Python is used for data cleaning and exploratory analysis, SQL is used to query and analyze the data, and Power BI is used to create interactive dashboards and visualizations. The analysis provides meaningful insights into customer segments and purchasing behavior, helping businesses make data-driven decisions and improve customer engagement strategies.

project done using python for EDA,SQL to answers for business questions and power bi for dashboard creation
